# 01 Peano Systems

## Core review cards

What is the basic purpose of a Peano system? >> To characterize the natural-number structure using a first element, successor, and induction.

What distinguished data does a Peano system contain? >> A carrier set, a distinguished first element, and a successor function.

What does injectivity of the successor function mean? >> If $S(a)=S(b)$, then $a=b$.

What does the Peano first-element axiom say? >> The distinguished first element is not the successor of any element.

What is the role of the induction axiom? >> A subset containing the first element and closed under successor must contain every natural number.

State induction in subset form. >> If $1\in A$ and $n\in A\Rightarrow S(n)\in A$, then $A=\mathbb N$.

What is a sequence in its basic set-theoretic form? >> A function whose domain is $\mathbb N$.

What does it mean for a relation $\le$ to be reflexive? >> For every $x$, $x\le x$.

What does it mean for $\le$ to be antisymmetric? >> If $x\le y$ and $y\le x$, then $x=y$.

What does it mean for $\le$ to be transitive? >> If $x\le y$ and $y\le z$, then $x\le z$.
